# Desktop

Start `auditorylab-gui` without arguments, or open **Auditory Lab.app** on macOS. Choose the separate Apple silicon or Intel download for your processor; macOS 15 or later is required. Windows downloads contain `auditorylab-gui.exe`. `--version` prints product version, build counter and optional source revision without opening a device.

About is available from the macOS application menu or Windows/Linux Help menu. It shows the application icon, selectable product version/build and optional source revision, and Slint attribution. **Project website** opens the repository. **Licenses** opens the complete software and artwork terms; **Third-party licenses…** opens the bundled component notices and source reference. On macOS these resources stay inside the app when it is moved to Applications. An incomplete desktop package reports missing resources in the license window. Source builds display the embedded software/artwork terms, but component notices require a packaged distribution. Escape closes About or the license window.

## Window and navigation

Library and Workbench are the two destinations. Navigation, **Save sound** and **Show/Hide monitor** remain outside the scrolling document, as do **Task details…**, which opens the current status in Audio details, and an export's progress and **Cancel export**. Save always addresses the Workbench draft. The compact bottom transport retains the playing source, concise generated description, estimated elapsed time and Stop while the document scrolls or the monitor is hidden. Its Play/Stop button keeps one width for all of its labels, and the elapsed clock (`m:ss` or `h:mm:ss`, with the total for finite recipes) has a fixed column, so changing state or time never moves the controls. An ordinary Stop or completion is shown there, not repeated in the document status. Idle transport identifies the next Play target; full source and generator information is available through **Details…**.

The optional **Output monitor** is a bounded lower drawer above transport, with its own title, separator and Hide control. Drag its divider, use arrow keys or its accessibility slider actions to adjust its height. Its lower bound follows the measured labels and controls; if they cannot fit within the drawer bound and available document space, the focused monitor window supplies them. Drawer choice, capture controls and document focus survive refresh/navigation. This also preserves document space at larger text sizes or small window heights. The separate focused monitor has one scroll region for content that exceeds its viewport. Tab reveals each control; Page Up/Down scroll vertically, and Ctrl+Home/End (Command+Home/End on macOS) reach the top-left or bottom-right, including warning text. When a focused monitor window disappears, focus returns to the monitor opener. Hiding an unfocused monitor preserves editor focus and pending text. Detailed diagnostics open separately, with selectable text and explicit **Refresh diagnostics snapshot**; they do not scroll inside the drawer or continually replace a selected reading.

## Library

**All** contains active Built-in and User entries. **Built-in** is read only; **User** contains managed local records. **Open files** are temporary and disappear on restart; **Trash** is separate from active results. Selection never plays audio. A missing default library starts empty without being created by browsing; **Save sound** initializes it on first publication. An absolute `AUDITORYLAB_LIBRARY_DIR` overrides the native data root and requires explicit initialization. **Library storage and recovery** shows the actual path, initialization/inventory diagnostics and Recheck. An unavailable root does not silently select another location.

Search normalizes Unicode and requires every term; bare numeric terms match whole values. Delta, Theta, Alpha, Beta and Gamma have prominent shared-reference intervals and unique counts, followed by Other rates, No rhythmic rate, Multiple rhythms and Needs review. Band/method restrictions match the same process. Nominal classification describes authored audio structure, independent of device-rate validity or EEG. See the [reference convention](catalog.md#nominal-rhythm-references).

Collection and Sort remain visible. **More filters and grouping** offers current-condition study, population, condition role, analysis coverage, direction, grouping and Created/Modified/Added here ranges. Study/role/population must belong to the same evidence record; ancestor evidence does not validate the current sound. Calendar fields use inclusive local YYYY-MM-DD dates through the next local midnight, including daylight-saving changes; the timezone is shown. Invalid/inverted ranges retain the prior query with an error. Unknown dates stay Unknown, fail bounded ranges and sort last in either direction. Automatic ordering follows scope; explicit sorts survive scope changes. Group headings reference unique sounds, so repeated band/method membership does not inflate the count. Clear filters preserves collection/sort; **Show saved** explicitly reveals the confirmed saved entry and clears restrictions. Saving itself preserves filters.

In compact list mode, **Filters / recovery…**, **Refresh** and **Clear all filters** remain reachable even with no matching sounds or an unavailable root. Back restores the list's selection and scroll. Empty views also offer **Create sound** and **Open Recipe…**. Incomplete inventories show a banner and observed counts rather than an authoritative empty-library count.

The applied-filter summary identifies the actual committed search, bands/methods, rhythm state, study/population/role values, analysis coverage and exact date bounds, including local offsets and UTC. It appears above compact results and beside the wider filter controls; scroll to read a long summary. This is the complete accessible equivalent of separate chips. Unsubmitted or rejected form text never replaces it. **Clear all filters** clears restrictions, while **Reset sort** restores the current scope's automatic order/direction without clearing filters or grouping.

Rows include duration and the primary date for the effective sort. User rows retain Edited, with Added here also shown when edit history is Unknown; Added here never substitutes for the edit sort key. Details display local time with an explicit UTC offset, including the historical offset at each instant. **Exact UTC dates** opens selectable canonical timestamps without changing stored history or CLI UTC output.

Rows show collection/read-only identity and nominal structure. Details separate Created/Modified portable history from Added here/Trashed here local history, explain classification and provide scoped sources/ancestry. Declared future or reversed chronology is diagnosed, never clamped. Study URLs open only through an explicit action. The research disclosure opens selectable citations, populations, limitations and sound adaptations.

**Listen** starts finite playback; a managed selection is rechecked against storage before preparing the device. Changed or trashed saved content is refused rather than silently substituted. **Stop current & play recipe** explicitly replaces the prior session. **Preview waveform** selects a seekable preview while audio is idle. Browsing, saves, refreshes and membership changes do not retune or rename a captured playing session.

**Edit a copy** receives a fresh portable UUID, preserves notes/bibliography and bounded flat ancestry, and demotes retained findings to ancestor scope. Built-ins offer no rename/delete/replace capability. **Edit saved User recipe** retains the selected User identity and exact expected version. **Edit external file** retains the shown external path and observed file version. Existing dirty work receives Save/Discard/Cancel protection. Copied-from snapshots remain inspectable during this session; reopened lineage does not reconstruct an ancestor waveform.

**Open Recipe…** parses a regular TOML file into Open files without persistent membership. **Add to User Library** explicitly copies portable content into the managed store; it never changes the external source. A reserved built-in UUID or same-ID conflict requires an explicit independent copy. **Close open file** removes only its temporary entry. Export portable recipe retains identity/history and strips local membership; Export WAV validates the captured selected content at the export rate.

User entries can be renamed or moved to Trash using their captured key/version. Dirty edits receive Save/Discard/Cancel before Trash; a failed or uncertain operation retains the draft, and later edits cannot be discarded by an older completion. Restore preserves recipe history and Added here. Permanent deletion is offered only for Trash and requires a native confirmation naming the exact title and identity, followed by a fresh expected-version check. No operation cascades to ancestors, independent copies or original files.

Refresh is explicit and also queued on native focus regain. Incomplete inventory keeps healthy rows and previously unseen last-observed rows with a visible warning; it does not claim an authoritative empty library. Stop stays independent of busy/unavailable library work. List keys, pointer gestures and rename entry retain the identity/version they began with. Keyboard arrows/Home/End navigate unique results; Enter/Space opens details without playing audio. Compact layouts have **Back to recipes**, preserving query and selection.

## Workbench

An empty sound is silence. **New**, **Add steady tone** and **Add click rhythm** are in the document. Up to 16 components retain stable technical component IDs. New components start at −30 dBFS in both ears without modulation.

Each component leads with its role, physical context and directly editable frequency/rate, width, level and applicable modulation controls. Ears, carrier, modulation and **Remove** sit in an explicit disclosure; active effects and validation errors remain apparent when it is closed. **Undo remove** puts the most recently removed component back in its place, with any text typed into it, until another component is removed or the sound is replaced; at 16 components it waits until one is removed. Technical IDs are in Pattern explained. Exact fields use Hz, milliseconds, dBFS and percent. Sliders use three significant digits for frequency/rate/width, 0.1 dB for level and whole-percent depth. Compact layouts retain exact fields while hiding sliders.

Typing stages text: diagnostics and action availability follow it, but the sound does not. Enter, leaving the field or an action commits the whole sound at once. If any typed entry does not parse or any value is not a finite number, nothing is applied and every typed entry stays for correction. Otherwise all entries apply together, including values the sound cannot play, so the draft can be saved and repaired. Escape restores the field's committed value. Changing a carrier or modulation discards typed entries only for the fields it removes. Pending text survives monitor, font, status and other components' updates. A live session plays committed values that are valid at the device's rate; an invalid commit keeps the last valid sound. Before the device is opened, Play needs only complete finite values: the device's actual rate decides validity, independently of the export rate. Parser/validation messages identify affected settings, with coupled rate/width or sideband constraints naming both inputs. Aggregate peak errors describe the mix. Metadata changes do not restart audio transitions.

**Pattern explained** expands beside a component within the document. It is a static, origin-zero core timing/envelope model of the selected recipe, the committed draft or, while it plays live, the session's accepted settings, with explicit source, rate and revision. It keeps click/gate/AM processes and interaural relationships distinct. It is independent of the actual-output drawer and live phase history. Projections aim for four cycles in 250 ms–4 s, bounded to 32 lanes × 512 columns; very slow processes identify an incomplete cycle.

Sound settings contain custom notes, attributed source context, saved duration/fades and export rate. Duration/fades affect finite playback and WAV export; live playback continues until Stop or its frame limit. The live device rate remains separate from the preview/export rate.

## Actual output and transport

The drawer displays actual mixed stereo samples after generator ramps, fades and clamping, before device conversion. It can also show a clearly labeled seekable preview. **Live**, **Held**, **Stale**, **Waiting**, **Unavailable** and **Last capture** describe the display independently of Playing/Stopping/Stopped/Failed transport. Receipt age (“received samples just now”, “12 s ago”) advances from genuinely changed publications, not redraws. A stationary periodic trace can be live; no artificial motion is added.

Choose a visibly selected 2/10/40/100 ms window and **Fit signal** (the default) or **Fixed ±1**. Fit uses one symmetric stereo limit and preserves channel balance; silence uses ±1. Scaling changes geometry, not samples or meters. Extrema retain brief pulses and both polarities. Time/amplitude references and sample peak/RMS describe the actual captured window. Raw history stays bounded to 100 ms; static models do not enlarge it.

**Hold display** retains source/session, rate, frame span, sequence, observation, scale and meters together. Audio, editing, transport and warnings continue. A held older source stays explicitly identified after browsing, replacement or Stop. **Return to live** takes the latest available coverage. Ended sessions show Last capture and historical levels. Historical skipped monitor publications remain in diagnostics; only current stale/unavailable/incomplete coverage produces a monitor warning. Backend-reported output underruns remain distinct and visible.

Native motion preferences distinguish Reduce Motion enabled, disabled and unavailable. Enabled defaults to a held display; disabled permits live drawing. Unavailable uses an explicitly diagnosed live fallback. Hold/Return to live is an explicit override; **Follow system motion** restores native preference control. macOS uses AppKit's accessibility preference, Windows queries client-area animation, and Linux uses GNOME GSettings or KDE's settings portal; unavailable preference sources retain the diagnosed fallback. Preference I/O stays outside audio processing.

Generated descriptions retain independent rhythms, steady companions, interaural/monaural pair conditions and outgoing/incoming crossfade roles. Exact rates, source/session, accepted/active/settled revisions and counters are in Audio details. Output elapsed uses backend timestamps; generator observations are not a latency-aligned acoustic playhead.

Live level/routing/depth changes ramp over 30 ms. Tone/AM rates glide continuously; source/modulation kind and pulse rate/width changes crossfade. Finite Stop fades over up to 30 ms. Live Stop can finish a current transition before its 30 ms fade, so almost 60 ms of generation plus device buffering can remain. Live lifetime is bounded to 2^36 frames, about 16 days at 48 kHz.

## Saving, file tasks and quit

**Save sound** commits and captures an immutable draft. New/custom drafts save to User Library; an existing User edit targets its stable key and expected version; an external edit targets its displayed observed file. **Save independent copy** forks a new User identity with scoped ancestry. Export portable recipe does not fork or mark a draft saved. A location label distinguishes Unsaved, User Library and External file from selection and playback.

One audio session and at most one file task have independent completion/cancellation. A later edit remains dirty after an earlier snapshot publishes. A result from an older document cannot mark a replacement draft saved. Saved classification follows the exact published content and history; saving does not detach live control or clear a held monitor.

Save accepts serializable finite-invalid sounds for repair. Unparseable/nonfinite fields and documents over 64 KiB are rejected; Play and WAV export separately validate at their respective rates. Existing managed and external saves check their observed versions even for no-op. No-op preserves dates/revision/bytes. A meaningful edit records the actual observed modified time; missing imported creation history remains Unknown.

Publication synchronizes and verifies a sibling stage before the commit step. Pre-publication failures leave the saved version and baseline intact. Confirmed publication with durability/cleanup warnings remains saved. **Publication unconfirmed** retains the exact candidate/receipt and blocks blind retry; **Recheck publication** rereads without republishing. An observed original permits explicit retry; different content or absence requires reconciliation. Missing after restart proves absence rather than attributable purge success. **Save independent copy** is an explicit alternative and retains the prior recovery receipt for the session. Orphan stages are reported, never automatically promoted or deleted.

A concurrent-editor conflict retains the current draft. Refresh and **Edit saved User recipe** provide reload through Save/Discard/Cancel; Cancel keeps the draft, and Save independent copy gives it a fresh identity. There is no force-overwrite route. Adjacent external-file locks coordinate Auditory Lab writers, but other applications may ignore them: a race after the final identity/hash check cannot be excluded. Managed operations do not write external originals. Stop cannot cancel or undo an already published file.

During macOS file selection an in-panel **Stop audio** button addresses only audio, leaving the panel open. Windows/Linux expose independent modeless **Audio controls** while the owner has a native file dialog. Ordinary transport remains available during the file job itself. **Cancel export** is separately named; WAV export requires idle audio to avoid competing render workloads. Import shares the single file slot and only populates Library.

New/copy/close/File Quit/native macOS Quit protect dirty content with Save/Discard/Cancel, through one shared decision; repeated Quit asks once. Resolve an already-open dialog before closing/replacing. The application closes only after audio and file tasks have stopped and finished; Cancel, a failed save or newer unsaved edits keep it open. Save-and-close will not discard newer edits. Cancellation/completion do not depend on monitoring. Forced process termination can leave a hidden `.NAME.RANDOM.partial` file beside an interrupted destination.

## Platforms

A downloaded macOS app may require **System Settings → Privacy & Security → Open Anyway** after its first launch attempt; see [Apple’s instructions](https://support.apple.com/en-us/102445).

Linux needs X11 or Wayland, fontconfig, xkbcommon, fonts, OpenGL and an xdg-desktop-portal with a desktop backend for native dialogs. X11 also needs `libxkbcommon-x11-0` on Debian/Ubuntu. Windows needs the matching architecture and an OpenGL 2.0 or newer driver. Fatal Windows application errors appear in a native dialog, including failure to create a graphics context. See [source prerequisites](../README.md#build-from-source).

For a Linux desktop download, keep the extracted folder and its legal materials together, add that folder to PATH, install `auditorylab-gui.desktop` under `~/.local/share/applications/`, and merge the packaged `hicolor/` contents into `~/.local/share/icons/hicolor/`. Keep the `org.resoltico.auditorylab` icon names unchanged. Run the executable directly from its original folder if installing no launcher.

Typography uses the platform SystemUi family, AppKit’s system size on macOS, Windows message metrics at 96 DPI, and toolkit DPI scaling on Linux. GNOME Wayland text scaling uses GLib’s `gsettings` utility on one bounded worker. X11 uses the toolkit’s Xft DPI path without a second text multiplier. Menu/context-menu routing retains ordinary backend handling.

The UI renders with Slint/OpenGL; synthesis runs on the CPU. Keep device volume low before playback and use headphones for separate-ear sounds.

Custom recipe notes use a bounded multiline editor: Return inserts a line break; leaving the field or Save commits the staged candidate, and Escape restores committed notes. Titles and numeric quantities remain single-line. A bounded global refusal/task summary sits beside persistent transport actions, with complete selectable text in Details. Edit a copy preflights the finite numbers and metadata bounds of the selected captured document before replacing work. Untitled file names use their stem for display/output suggestions while source details keep the full path. A requested standalone monitor is presented after the main window at startup; later reflows preserve existing editor focus, and native presentation errors remain visible and retryable.

Committed edits immediately update **Draft classification**. Staged text shows **Last committed classification**; it never relabels invalid text as an analyzed value. **Saved version** follows the exact confirmed save candidate, so editing during an outstanding save can leave different draft and saved bands. Nominal classification is independent of target-rate validity. Library rows use cached nominal analysis; technical details validate the selected recipe at the stated rate.
